# Make Pages Selectable

A browser extension that makes text selectable on websites where text selection is disabled.

Tested with [Full Stack Cafe](https://www.fullstack.cafe/), where this extension allows normally unselectable interview questions to be selected and copied.

## Installation

### Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the extension folder
5. Open Full Stack Cafe and refresh the page

### Microsoft Edge

1. Open `edge://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the extension folder
5. Refresh the page

### Brave

1. Open `brave://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the extension folder
5. Refresh the page

## Project Structure

- `manifest.json` - Extension configuration
- `style.css` - Enables text selection

## Example

Tested on:

- [Full Stack Cafe](https://www.fullstack.cafe/)

## Updating

After changing the extension files:

1. Open the browser's extensions page.
2. Click **Reload** on the extension.
3. Refresh the webpage.
